# Transcrição de exemplo — Treinamento fictício

> Use esta transcrição pra testar a skill sem precisar de uma aula real
> gravada no Zoom. Nenhum nome ou empresa aqui é real.

**Treinamento:** Introdução ao Notion pra Times de Marketing
**Data:** 08/09/2026
**Duração:** 42 minutos

---

Oi pessoal, bom dia. Hoje a gente vai começar a organizar o time de marketing
dentro do Notion. Antes de mais nada: o objetivo aqui não é vocês decorarem
botão, é vocês entenderem a lógica por trás, porque aí qualquer ferramenta
nova fica fácil de aprender depois.

A primeira coisa que eu quero que vocês entendam é a diferença entre uma
página e um banco de dados. Uma página é só texto, como um documento. Um
banco de dados é uma coleção de itens que têm as mesmas propriedades — tipo
uma planilha, só que muito mais poderosa, porque cada linha pode virar uma
página cheia de conteúdo.

Vamos criar juntos o banco de "Campanhas". Toda campanha vai ter: nome,
status (Planejamento, Em andamento, Finalizada), responsável, data de início
e data de fim. Reparem que eu não coloquei "resultado" como campo obrigatório
ainda — isso a gente adiciona depois, quando tiver dado real pra preencher.

Uma dúvida que sempre aparece aqui: "e se eu quiser ligar uma campanha a uma
peça de conteúdo específica?" Isso se chama relação. Vocês criam um segundo
banco de dados, "Peças de Conteúdo", e ligam os dois. Não vamos fazer isso
hoje porque o time ainda não tem esse segundo banco pronto — fica como
próximo passo.

Outra coisa importante: view. A mesma base de dados pode aparecer de formas
diferentes pra pessoas diferentes. O gestor pode ver um calendário, o
executor pode ver um kanban por status. É a mesma informação, só filtrada e
organizada diferente.

Pra fechar, eu quero que cada um de vocês, até sexta-feira, cadastre pelo
menos duas campanhas reais do time no banco que a gente criou hoje. Não
precisa estar perfeito, o objetivo é só perder o medo da ferramenta.

Ah, uma pergunta que ficou em aberto: o Marcelo perguntou se dá pra puxar
automaticamente os dados de performance do Instagram pra dentro do Notion.
Isso é possível via automação (Make, por exemplo), mas não é o foco de hoje —
fica pra um próximo treinamento, quando o banco de campanhas já estiver
rodando de verdade.

Por hoje é isso, qualquer dúvida chama no grupo. Até a próxima.
