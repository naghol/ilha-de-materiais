# ATA

Skill do Claude que transforma a transcrição, gravação transcrita ou
anotações de uma reunião num plano de ação real — cada item com
responsável e prazo, separado do que foi só discutido ou já decidido sem
exigir ação de ninguém.

## Como usar — Claude Code (terminal)

1. Copie o arquivo `SKILL.md` desta pasta pra `~/.claude/skills/ata.md`
   na sua máquina (ou pra `~/.claude/skills/ata/SKILL.md`, os dois
   formatos funcionam).
2. Peça: "Claude, usa a skill ATA nessa reunião" e cole a transcrição.

## Como usar — app Claude (claude.ai / desktop)

1. Em Configurações → Capabilities → Skills, suba este `SKILL.md` como uma
   Skill customizada.
2. Cole a transcrição na conversa e peça pra extrair o plano de ação (ou
   simplesmente diga "ATA").

## Personalizando

O conteúdo do `SKILL.md` é o comportamento inteiro da skill — não depende de
nenhum script externo. Pra ajustar a estrutura dos blocos, edite o próprio
arquivo.
