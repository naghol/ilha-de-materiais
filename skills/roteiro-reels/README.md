# ROTEIRO-REELS

Skill do Claude que transforma um conteúdo, dado, trecho de livro, ideia ou
experiência pessoal num mini-roteiro de Reels/Shorts de 60 segundos, com
gancho estratégico nos primeiros 3 segundos e estrutura de 4 blocos pronta
pra gravar.

## Como usar — Claude Code (terminal)

1. Copie o arquivo `SKILL.md` desta pasta pra
   `~/.claude/skills/roteiro-reels.md` na sua máquina (ou pra
   `~/.claude/skills/roteiro-reels/SKILL.md`, os dois formatos funcionam).
2. Peça: "Claude, usa a skill ROTEIRO-REELS nesse conteúdo" e cole ou anexe
   o material.

## Como usar — app Claude (claude.ai / desktop)

1. Em Configurações → Capabilities → Skills, suba este `SKILL.md` como uma
   Skill customizada.
2. Cole o conteúdo na conversa e peça pra montar o roteiro (ou simplesmente
   diga "ROTEIRO-REELS").

## Personalizando

O conteúdo do `SKILL.md` é o comportamento inteiro da skill — não depende de
nenhum script externo. Pra ajustar o banco de ganchos ou a estrutura dos
blocos, edite o próprio arquivo.
