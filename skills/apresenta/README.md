# APRESENTA

Skill do Claude que transforma um texto, PDF, artigo, anotação ou argumento
numa mini apresentação visual — slides navegáveis (artifact HTML), com
narrativa em sequência: abertura, desenvolvimento e fechamento.

## Como usar — Claude Code (terminal)

1. Copie o arquivo `SKILL.md` desta pasta pra `~/.claude/skills/apresenta.md`
   na sua máquina (ou pra `~/.claude/skills/apresenta/SKILL.md`, os dois
   formatos funcionam).
2. Peça: "Claude, usa a skill APRESENTA nesse conteúdo" e cole ou anexe o
   material.

## Como usar — app Claude (claude.ai / desktop)

1. Em Configurações → Capabilities → Skills, suba este `SKILL.md` como uma
   Skill customizada.
2. Cole o conteúdo na conversa e peça pra transformar em apresentação (ou
   simplesmente diga "APRESENTA").

## Personalizando

O conteúdo do `SKILL.md` é o comportamento inteiro da skill — não depende de
nenhum script externo. Pra ajustar tom, paleta ou estrutura, edite o próprio
arquivo.
