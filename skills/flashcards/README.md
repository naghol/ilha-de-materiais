# FLASHCARDS

Skill do Claude que transforma um texto, PDF, artigo ou conjunto de
conceitos num baralho de flashcards interativos (artifact HTML) pra revisão
e memorização ativa — card com frente (pergunta/termo/pista) e verso
(resposta/explicação), navegável um por vez.

## Como usar — Claude Code (terminal)

1. Copie o arquivo `SKILL.md` desta pasta pra
   `~/.claude/skills/flashcards.md` na sua máquina (ou pra
   `~/.claude/skills/flashcards/SKILL.md`, os dois formatos funcionam).
2. Peça: "Claude, usa a skill FLASHCARDS nesse conteúdo" e cole ou anexe o
   material.

## Como usar — app Claude (claude.ai / desktop)

1. Em Configurações → Capabilities → Skills, suba este `SKILL.md` como uma
   Skill customizada.
2. Cole o conteúdo na conversa e peça pra montar o baralho (ou simplesmente
   diga "FLASHCARDS").

## Personalizando

O conteúdo do `SKILL.md` é o comportamento inteiro da skill — não depende de
nenhum script externo. Pra ajustar o sistema de design ou a paleta, edite o
próprio arquivo.
