# INFOGRAFICO

Skill do Claude que transforma um texto, PDF, artigo ou conjunto de dados
num infográfico visual único e autocontido (artifact HTML) — pronto pra
postar, imprimir ou apresentar, entendido em 10 segundos de leitura visual.

## Como usar — Claude Code (terminal)

1. Copie o arquivo `SKILL.md` desta pasta pra
   `~/.claude/skills/infografico.md` na sua máquina (ou pra
   `~/.claude/skills/infografico/SKILL.md`, os dois formatos funcionam).
2. Peça: "Claude, usa a skill INFOGRAFICO nesse conteúdo" e cole ou anexe o
   material.

## Como usar — app Claude (claude.ai / desktop)

1. Em Configurações → Capabilities → Skills, suba este `SKILL.md` como uma
   Skill customizada.
2. Cole o conteúdo na conversa e peça pra virar infográfico (ou simplesmente
   diga "INFOGRAFICO").

## Personalizando

O conteúdo do `SKILL.md` é o comportamento inteiro da skill — não depende de
nenhum script externo. Pra ajustar os templates estruturais, edite o próprio
arquivo.
