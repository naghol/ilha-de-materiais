# Automação de DM no Instagram

Plano executável pra montar a sua própria automação de DM do Instagram
(comentou a palavra, recebe o link na DM), sem mensalidade de ManyChat. A
base é o [OpenReply](https://github.com/diwenne/openreply), de código aberto.

Dá pra fazer de graça no seu computador ou pagando cerca de US$ 8 a 15 por
mês pra ficar no ar 24 horas. Os custos estão detalhados no plano.

## Como usar — Claude Code (terminal)

1. Crie uma pasta vazia e abra o Claude Code nela.
2. Arraste o `automacao-dm-instagram.md` pra conversa e escreva **executar**.

Ou, sem baixar nada, cole no Claude Code:

```
Baixa com curl este arquivo pra esta pasta, lê inteiro e executar: https://raw.githubusercontent.com/naghol/ilha-de-materiais/main/guias/automacao-dm-instagram/automacao-dm-instagram.md
```

O Claude faz as perguntas antes de começar, roda os comandos e avisa quando
for a sua vez de clicar em algum painel (Meta, Instagram, Railway, ngrok).
Se a sessão acabar no meio, abra de novo na mesma pasta e diga **executar**:
ele continua de onde parou.

## O que você precisa

- Conta do Instagram profissional (Criador ou Empresa)
- Conta no Facebook (pro painel de desenvolvedor da Meta)
- Uma segunda conta do Instagram pra testar
- Computador com Mac, Windows ou Linux
- Claude Code (plano pago do Claude)

Serve pra automatizar a sua própria conta. Pra revender a clientes, a Meta
exige App Review.
