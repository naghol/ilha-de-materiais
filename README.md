# Ilha de Materiais

Coleção gratuita de skills, templates e documentos do [Método Naghol](https://metodonaghol.com.br) —
alimentada aos poucos, conforme sai no canal.

Gratuito, use e adapte como quiser (licença MIT).

## Skills

| Pasta | O que faz |
|---|---|
| [`skills/material-pos-treinamento`](skills/material-pos-treinamento) | Transforma a transcrição de uma aula/treinamento gravado no Zoom em um PDF de material pós-aula |
| [`skills/infografico`](skills/infografico) | Conteúdo → infográfico visual de leitura única (artifact HTML) |
| [`skills/flashcards`](skills/flashcards) | Conteúdo → baralho de flashcards interativos pra revisão e memorização |
| [`skills/quiz`](skills/quiz) | Conteúdo → mini-quiz interativo, com pontuação e feedback certo/errado |
| [`skills/apresenta`](skills/apresenta) | Conteúdo → mini apresentação visual navegável (slides) |
| [`skills/dashboard`](skills/dashboard) | Planilha/dado estruturado → painel visual personalizado, com mini-entrevista antes de desenhar |
| [`skills/raiox`](skills/raiox) | Revisão crítica de contrato/proposta/e-mail antes de enviar |
| [`skills/ata`](skills/ata) | Transcrição de reunião → plano de ação com responsável e prazo |
| [`skills/roteiro-reels`](skills/roteiro-reels) | Conteúdo/dado/livro → mini-roteiro de Reels de 60s com gancho estratégico |

Cada pasta é independente — copie só a que você precisa, tem seu próprio
`README.md` com instruções.
